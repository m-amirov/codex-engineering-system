## Route-conditioned promises

Only record **material** reader expectations; incidental description and purposeful ambiguity are not automatically promises.

| Promise ID | Route / condition | Player-visible setup scene/cue (or planned) | Expected consequence | Reinforcement (optional) | Resolution scene/cue | Status | Evidence / author decision |
| --- | --- | --- | --- | --- | --- | --- | --- |
| | | | | | | | |

Statuses: **planned** (no authored proof), **authored** (source exists), **runtime-verified** (executed relevant route checked), **intentionally-open** (author-approved), **unresolved** (repair/decision needed). Do not promote statuses without evidence. Each branch may have a different or absent payoff when explicitly designed.
