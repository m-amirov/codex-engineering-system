# Optional future narrative-concept and payoff workflow

## Scope
This is an original CEOS adaptation of general planning ideas inspired by [Novel Creator](https://agentskill.sh/@majiayu000/novel-creator). No upstream code, instructions, EPUB scripts, templates, genre presets or required questionnaire are imported. This opt-in editorial procedure applies to **future** narrative projects only. It does not modify the currently shipping visual novel or introduce new release gates.

## Roles and steps
1. **Concept trial:** `romance-narrative` can compare a few differentiated premises and consequential reader/player choices, only if requested or materially useful. The author approves the actual story.
2. **Episode architecture:** record goal, agency, emotional movement, conditional choices, consequences, and a natural transition/hook. Quiet resolution is valid.
3. **Promises:** use `templates/narrative/STORY_PROMISE_LEDGER.md` for material route-specific setup, reinforcement and payoff (or deliberately open threads). Distinguish planned/source-authored/runtime-verified.
4. **Sequential writing:** one native parent writer carries a small verified next-episode context packet, not the entire script repeatedly.
5. **Independent editorial checks:** `reader-experience-review` tests blind expectations before seeing the author's ledger; `narrative-continuity-engine` verifies route/canon assumptions; `narrative-dialogue-editor` checks actual speech and subtext.
6. **Product verification:** the game/Starter Kit, if separately and explicitly enabled, owns real route graph, state, save, locale and runtime validations. Editorial appeal and reader engagement are not mechanically provable.

## Stop and provenance
Source snapshots, actual player-visible scene/cue and route guard are required for real defect claims. Unwritten payoff is NOT_VERIFIED, absent route evidence is EVIDENCE_GAP, authorial taste remains an editorial decision. Avoid arbitrary numeric story ratings, automated full rewrites, fake human-reader approval, required EPUB, mandatory interview, fixed word counts, and overlong Web High loops.

## Deferred Starter Kit work
After the user's Codex Starter Kit report is reviewed, consider an **optional** typed promise ledger attached to `narrative-game`. Deterministic checks may cover valid scene IDs, guards and annotated payoff references only. Do not claim that graph validation proves an earned emotional resolution. No change to Starter Kit or the current game occurs as part of this CEOS task.
