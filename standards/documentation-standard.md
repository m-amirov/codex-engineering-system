# Documentation Standard

Ownership: README = purpose/quick start; PRODUCT = value/scope; ARCHITECTURE = components/boundaries/flows/invariants/state machines; DEVELOPMENT = environment/run/debug; TESTING = levels/commands/matrix/evidence; RELEASE = build/package/checksum/publish/rollback; STATUS = factual state/risks/blockers/next; SECURITY = trust boundaries/secrets/services/permissions/logging/incidents; ADR = long-term decisions.

One fact has one primary home. Other files may summarize and link. Do not document unimplemented behavior as existing behavior. Before release candidate, remove unresolved `<!-- PROJECT: ... -->` placeholders from required sections.
